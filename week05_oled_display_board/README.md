# Week 5: ATtiny1614 OLED display board

An "echo hello-world" board with a button, LED and OLED display on an ATtiny1614, programmed over serial UPDI. It was designed as the audio display for the dashboard of the Oliya electric ATV (see `oliya_project`).

![Week 5: ATtiny1614 OLED display board](../docs/images/week05/final-board.jpg)

Full write-up: [week05_electronics_design.md](../docs/writeups/week05_electronics_design.md).

_Part of [htmaa_2022](../README.md), MIT How to Make (Almost) Anything, fall 2022. Formerly `misha_project`._
